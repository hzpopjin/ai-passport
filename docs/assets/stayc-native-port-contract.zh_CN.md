# STAYC 原生玩法与存储契约

本文描述获得授权的本地开发实现。原始 V4 模型最终源码尚未恢复；本地比较使用保留的 v15 WASM／JS 及较早 C 场景源码。这些参考材料、直接移植的玩法／模型、动画、生活、装饰、反应模块、运行轨迹及提供的图片因再分发许可待确认而排除出公开快照。本项目不声称完整恢复原始源码，也不声称公开版本可独立构建。参见[开发指南](stayc-development.zh_CN.md)及[版权声明](copyright-notice.zh_CN.md)。

## 玩法边界

本地目标含六位成员、每位两套真实衣装、384 个姿态格、三个房间、八种丰富互动及六组完整版／副歌。原生成员／衣橱导航围绕保留的玩法契约集成。旧版第三套衣装值保持不变；界面仅提供两套真实 STAYC 衣装，将旧值描述为历史记录，不虚构新图片。

生活活动、有限小卡反应、接接乐／记忆／旅程规则、四个装饰位及余额／购买行为，与固定的本地参考比较。暂停冻结场景时钟，取消不发完成奖励，首次完成奖励不重复；购买采用准备 → 验证 → 持久化提交 → 完成。预览／取消不改变已提交余额。主机差分一致证明覆盖轨迹中的行为，不证明完整实卡时序或全部功能一致。

播放器控制比较真实本地 JS／WASM 播放器与原生包装层。顺序／随机／单曲模式及完整版／副歌集合相互分离。切歌和快进退保留暂停状态，跳过时间／倒计时／解码预热不获得收听奖励。历史最多 256 条，较早记录被丢弃，不持久化。UI 场景绘制不修改玩法状态。

## 存储与手机通信

默认卡片通信为 `pocket-phone-jwt-v1`。账号 JWT 和后端 HTTP 留在手机。只有显式定义 `H2H_CLOUD_HOST_LEGACY_TEST` 选择旧版主机路径时，`h2h_cloud.c` 才不使用手机桥接。较早的 Wi-Fi／签名中继及 cloud48 描述是历史契约，不是当前正常构建。参见[手机协议](../development/pocket-phone-jwt.zh_CN.md)。

| 记录 | 契约 |
| --- | --- |
| 旧基础进度 | 48 字节；作为独立投影保留，不改解释成 V4 |
| 归属 | 既有 384 字节记录及归属 epoch |
| 原始 V4 玩法 | 92 字节、版本 4，明确校验和及旧版迁移验证 |
| 原生完整存档 | 164 字节，schema／版本检查、小端字段，base48 偏移 16、gameplay92 偏移 64、已付旅程标记偏移 156、校验和偏移 160 |
| 成员偏好 | 既有 24 字节、epoch 范围内的选择记录 |

完整存档 bank／pointer 日志将全部进度绑定归属，支持重启恢复和不可变的传输中确认。旧 160 字节本地包装及 48／72／76 字节玩法记录仅通过经过验证的编解码器迁移。无效、未来版本或读失败记录受保护，不覆盖。当前协议同步完整 164 字节记录，客户端不得代入旧 48 字节存档示例。

冲突保留完整本地与远端记录并锁定玩法。明确实卡恢复采用远端记录，同时保留本地恢复数据；重连后完成恢复确认。旧的传输中回执确认后，较新的本地数据仍保持待同步。不同归属 epoch 不继承前所有者的钱包、玩法或已付标记。解绑及归属变更受 generation 防护。开发沙盒退出时恢复正常进度，不授予账号权益，也不持久化普通玩法。

## 分区与运行时边界

默认表保持 NVS `0x9000/0x6000`、PHY `0xF000/0x1000`、factory `0x10000/0x7F0000`，无外部资源／资料／日志 bank。可选候选分区表不授权改变设备布局。应用剩余空间不等于外部资源容量；不提供两份完整固件 OTA 槽。

LVGL 池为 48 KiB，单个解码图集帧为 15,360 字节。链接 DIRAM 余量不等于启动／运行时 heap。需在真实并发音频、显示、蓝牙与手机同步时测量 heap 最低值、最大块及任务栈最低余量。LVGL 任务外访问 UI 需要 BSP 锁，慢操作不能放在按钮回调内。

## 验证与实卡交接

有另行获得授权的本地输入时，运行 `./tools/validate.sh --all --segmented`，再以 `tools/archive_segmented_firmware.py verify <archive-directory>` 验证归档。检查从受控默认配置构建，核验 8 MiB 最小布局、ELF／app 身份及应用余量，并用主机桩及本地参考材料测试实际源码。分段模式不生成填充合并镜像，也不写设备。

真实启动、中文显示、重复手势、实际声音、蓝牙重连／激活、完整存档恢复、归属切换、断电持久化及运行时内存属于独立验收。获得刷写批准前，明确准确产物、设备、兼容布局和数据影响。遵循[固件数据政策](../development/engineering/firmware-layout.zh_CN.md)，不得发布嵌入被排除输入的固件。
