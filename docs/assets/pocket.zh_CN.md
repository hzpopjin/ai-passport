# Pocket 使用指南

Pocket 是 AI Passport 上的口袋伙伴应用，团体及成员是可选内容。所选团体内容包提供图片、歌曲和房间配置；日常操作、音乐、游戏与存档机制以本指南为通用入口。公开分支是开发快照，不包含可直接刷写的固件及全部私有材料。如果从源码开始，请阅读[开发指南](pocket-development.zh_CN.md)；使用媒体前请阅读[版权声明](copyright-notice.zh_CN.md)。

## 选择喜欢的内容

从设备和兼容手机客户端提供的内容中，选择喜欢的团体与成员。团体决定图片、歌曲和衣装，不改变应用名称 Pocket。请确认资源集合已获授权，并且设备固件支持。可选团体、成员和曲目数量取决于这套配置。更换内容包需要匹配的固件／资源及兼容存档；当前实现边界见[开发指南](pocket-development.zh_CN.md)。

## 第一次使用

1. 打开设备。未激活卡片显示设置二维码和引导地址；已激活卡片进入主界面。
2. 首次激活需要支持 `pocket-phone-jwt-v1` 的手机客户端及配套后端。本仓库较早的网页／小程序集成快照不能证明兼容该协议。
3. 在手机登录账号，按提示授予蓝牙和相机权限，通过设置二维码或客户端连接流程找到设备。选择正确的 `RDP-…` 卡片，核对设备与手机上的蓝牙配对码后再允许配对。
4. 在手机客户端完成激活。保持手机与卡片靠近，直到手机报告卡片已持久化确认成功、卡片进入主界面。扫过二维码或显示蓝牙连接图标，都不等于激活完成。
5. 激活成功后，本地玩法无需手机持续连接。需要同步进度时，用同一账号重新连接。首次激活及在线同步依赖兼容的客户端与服务。

登录令牌留在手机，后端访问也由手机完成。卡片通过蓝牙接收有长度限制的消息，把归属和存档保存在本地；默认构建不接收 JWT，也不通过 Wi-Fi 访问后端。保存的蓝牙绑定可用于再次连接。

## 三个按键怎么用

**上／下键**选择项目，**短按 OK**进入或确认，**长按 OK**通常返回。长按从 500 毫秒开始识别；松开后不会再触发短按。播放器的部分操作需要等待连续点击窗口，短暂延迟属于预期行为。

| 页面 | 上／下键 | 短按 OK | 长按 OK |
| --- | --- | --- | --- |
| 首页 | 选择小房间、随身听、游乐场、收藏册、应援牌、设置或用户信息 | 打开选中页面 | 按页面提示操作 |
| 小房间 | 选择招呼、比心、衣橱、背景、生活、布置、成员或互动 | 打开／执行选项 | 首页 |
| 成员／互动选择 | 选择成员或互动 | 应用成员或开始互动 | 小房间 |
| 互动／生活场景 | 按选中场景的提示操作 | 暂停／继续；完成后重播 | 取消／返回 |
| 衣橱／背景／装饰 | 预览物品 | 应用已拥有物品；显示购买提示时确认 | 取消／返回 |
| 音乐菜单／歌曲列表 | 选择歌曲、完整版／副歌、播放模式或倒计时 | 应用／打开 | 上一页 |
| 播放器 | 短按一／两次：每次音量 ±5；三次：上一／下一首；长按：快进／退 10 秒 | 播放／暂停或取消倒计时 | 音乐菜单 |
| 接接乐 | 左右移动接物篮 | 暂停／继续 | 离开，不领取完成奖励 |
| 记忆游戏 | 演示结束后输入展示的方向 | 按当前阶段提示操作 | 离开／返回 |
| 收藏册／小卡 | 选择小卡 | 打开小卡或设为应援牌 | 上一页 |
| 应援牌 | 按页面提示操作 | 按页面提示操作 | 首页 |
| 设置／用户信息 | 选择可用项目 | 应用／打开 | 返回原入口 |

播放器中，同一方向键连续三次短按、相邻间隔不超过 800 毫秒，会切歌：上键上一首，下键下一首。一／两次短按在窗口结束后调整音量。快进退和切歌保留暂停状态并取消倒计时。长按 OK 离开播放器后，音乐继续播放。顺序循环、随机播放和单曲循环都在选中的完整版或副歌集合内运行。播放历史最多保留最近 256 条，重启后不保留。

## 探索、收集和购买

- 成员、衣装、房间和互动按所选内容包提供。提供的媒体不随公开仓库分发。
- 成功写入 PCM 音频输出累计 120 秒，获得一颗爱心。暂停、倒计时及跳过的时间不计入；该统计不能证明扬声器实际发出了声音。
- 完成游戏、生活活动和旅程目标，可获得界面显示的奖励。提前离开不获得完成奖励；部分成就只发放一次奖励。
- 每累计五颗爱心解锁一张尚未拥有的小卡，直到集齐八张。爱心与商店星星是两种数值，购物花费星星；账号网站积分又是独立的第三种数值。
- 预览或取消购买不扣星星。选中变更持久化成功后才完成购买；存储失败会保留之前的余额和装备。
- 应援牌展示已拥有的小卡。旧存档可能保留第三套衣装的记录；可选衣装以所选内容包的实际资源为准。

## 存档、用户信息和隐私

进度、获得的物品和设置保存于本地。当前手机完整存档协议传输 164 字节记录，包含玩法和归属范围内的元数据；旧的 48 字节集成示例属于其他协议。重启不恢复未完成游戏、动画或播放位置。突然断电可能丢失最近尚未提交的进度。

更换所有者会进入独立的归属 epoch。同步出错时，不要通过清空 NVS、重新绑定或擦除设备来修复。本地与远端存档冲突时，玩法锁定，两份数据都保留。“恢复”明确采用远端存档，并保留原本地记录供恢复，不合并余额。在设置二维码页，先松开所有按钮，依次短按上–下–上–下，长按 OK 至少三秒后松开，再在确认提示出现时短按 OK，可进入诊断菜单。选中“恢复”，保持选项不动，在五秒内短按 OK 两次。之后重新连接手机完成恢复确认。长按 OK 退出诊断菜单。

用户信息展示最近一次同步的资料。蓝牙图标表示已连接，不代表通过认证或同步成功。任意账号昵称可能超出内置字体字库。头像／资料持久化需要经过评审的资料候选分区，默认仅含 factory 的布局不提供该容量。外部资源安装和循环诊断记录同样需要另行评审的布局；默认构建不应被视为具有这些功能。

## 遇到问题怎么办

| 现象 | 建议操作 |
| --- | --- |
| 一直停在设置二维码页 | 确认客户端支持当前手机协议，登录正确账号，打开蓝牙并重新连接。旧客户端可能不兼容。 |
| 配对码失败或连接中断 | 核对手机与卡片的配对码，靠近设备，从设置／账号页重试，并检查手机蓝牙权限。 |
| 设置链接无法打开 | 使用兼容客户端的设备连接流程。设置页面是否已发布、账号服务是否可用，需要单独验证。 |
| 没有声音 | 调高音量并恢复播放；请固件维护者检查本地音频输入和扬声器。编译通过不能证明实际有声音。 |
| 存档冲突或存储错误 | 停止反复购买／恢复，保留本地数据，记录显示的错误并求助维护者。只在打算采用远端存档时执行恢复。 |
| 头像为空或资源不支持 | 核对已安装的分区变体。默认布局没有外部资料／资源存储区。 |
| 昵称出现方框 | 使用内置字库覆盖的昵称，或申请补充字体。UTF-8 正确不代表字形齐全。 |

求助时，请在 [Issue](https://github.com/hzpopjin/ai-passport/issues) 中提供固件版本、设备／手机型号、客户端版本、准确操作步骤及脱敏错误码。不要提交完整二维码链接、配对码、令牌、密码、个人账号资料或原始日志。不要将刷入未验证固件或全片擦除当成常规排障手段。升级需使用经过验证的镜像、兼容布局并获得明确批准，参见[数据政策](../development/engineering/firmware-layout.zh_CN.md)。
