# Pocket 公开源码准备情况检查

检查日期：**2026-10-07**。范围：[hzpopjin/ai-passport](https://github.com/hzpopjin/ai-passport) 当前 `feature/pocket-paired-firmware` 源码快照。本次为源码同步，不是打标签、发布 Release、提供固件下载、合并上游或部署服务。

## 发布边界

所有者要求排除再分发授权未明确的内容。因此公开快照不含全部 STAYC 图片输入及生成显示数据、参考 JS／WASM 目录、记录的 v15 运行轨迹，以及五组直接移植的源码／头文件（玩法／模型、动画、生活、装饰、反应）。音乐继续排除。这些内容留在本地并由 Git 忽略；固件／调试包不发布。[版权声明](../assets/copyright-notice.zh_CN.md)明确相关版权内容仅供个人学习研究、禁止商用，同时保留覆盖源码的 MIT 及字体的 OFL 许可。

检查的新源码包括手机辅助激活／完整存档同步、有容量限制的存储／资料／日志／资源适配器、UI 集成、BSP 生命周期／输入改进、主机测试和工具。被排除模块的接口仍保留，供获得授权的本地开发使用。这份部分源码快照**尚不具备独立公开固件发布条件**。

主机辅助脚本写死的临时 cJSON 路径已修正为与主检查相同的经过验证的仓库内缓存。macOS 的 OpenSSL 头文件／库仅通过当前进程提供。缺失私有输入时，验证明确报错，不会静默跳过并冒充通过。

应用名称已统一为 **Pocket**，团体／成员是用户可选内容。首页、使用指南、分支及通用文档名称不含团体名；固件中的房间、衣橱、应援牌和游戏标题也采用通用名称。素材清单中的真实路径保留，用于输入验证和来源核对。命名修正后重新运行完整分段检查，Build 与 Host tests 均 PASS；Device tests 仍为 NOT RUN。

## 本地构建身份

本次验证的本地应用为 5,948,976 字节，默认 factory 余量 2,374,096 字节。应用 SHA-256 为 `2e81b21947c6383172937a164001fd8bde38e50c1c9f00effd95877d8e64e595`，匹配 ELF SHA-256 为 `864967c414ce3ca268add38427ddb24620986f7d1d04d626691c27cd0143ec41`。分段归档留在被忽略的本地 `build/firmware-segmented/<app-sha256>/`，不提供下载。哈希证明对应产物身份，不证明授权或实卡行为。

注册辅助工具在已安装的 IDF Python 环境中完成 sanitizer、16 个服务器模拟测试、11 个主机测试和 API 边界检查；未生成真实密钥、注册账号、连接 USB 或刷写设备。依赖检查核对固定版本、完整性和随附许可；本次未开展在线漏洞数据库审计。

## 发布前仍需完成

1. 为每项被排除的素材、移植模块和测试材料取得书面再分发授权，或替换为符合目标发布用途的内容，并维护来源／许可清单。
2. 全新公开克隆必须无需未记录的私有输入即可通过完整检查。现有 Actions 固件／主机任务仍需要这些输入，不能把该快照描述为 CI 已就绪或通过。
3. 实卡验证启动、字库、时序、音频、蓝牙／配对码／重连、兼容手机／后端激活、完整存档恢复／冲突和归属切换、NVS／断电、运行时 heap／栈及所选候选布局。
4. 未来分发固件或 CI 产物前，检查嵌入媒体、秘密和数据。当前部分快照不得发布标签或启动固件上传工作流。

默认 NVS／PHY／factory 布局未改变。本次不启用或刷写资料／日志／资源候选布局。旧账号集成快照及 H2H 浏览器预览是历史参考，不证明兼容当前手机 JWT 协议。参见[使用指南](../assets/pocket.zh_CN.md)和[开发指南](../assets/pocket-development.zh_CN.md)。
