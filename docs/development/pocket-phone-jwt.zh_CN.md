# 手机 JWT 激活候选版

手机持有业务 JWT 并调用后端 3.17.0 手机接口。卡片不会接收 JWT，不读写中继密钥，不访问后端。经认证蓝牙读取的完整 ID 是定位信息；本玩具方案信任手机报告，不提供出厂防伪证明。

正常流程：扫码、系统蓝牙 PIN、手机 JWT 激活、蓝牙 phone_apply、原子持久保存归属及完整存档、进入主界面。同账号重试保留 epoch。完整 164 字节存档保留 schema4/version2/校验和、CAS 版本、本地代次隔离、显式冲突恢复、持久 ACK 与重连续传。卡片离线解绑经账号 JWT 收据及 phone_unbind 确认；旧收据不会影响后来绑定的账号。

保留已有 NVS 密钥、设置、存档、双银行日志布局、安全启动与 Flash 加密状态。生产编译仅使用 h2h_phone；h2h_cloud_legacy 仅用于显式选择的旧协议主机回归和回滚。候选固件不编译逐机密钥、签名中继或卡片访问后端的 HTTP 流程。

冲突时卡片锁定并保留本地及云端两份存档。在二维码页进入诊断菜单，选择 Restore，连续短按两次 OK 明确采用云端版本；移动选项、超时或归属/模型代次变化会取消确认。本地原版保留为 recovery，重连手机后才发送完整存档恢复 ACK。

8MB 默认分区没有外部资源银行，明确报告容量零；本候选版不能传输 Wi-Fi 资源。不可把资源选择称为已安装，不能占用应用分区。手机直传卡片的资源接收功能仍需实现，并需要批准兼容的资源布局。

编译及主机测试不能证明真机验收，刷写和生产启用保持暂停。若本地归属代次比后端更新，先核对归属，不能擦除或把旧绑定卡当作出厂新卡。旧基础存档恢复须在升级前完成。R6 回滚保留 NVS，但只用 JWT 登记的卡没有旧中继密钥，不能使用 R6 在线中继。
