# STAYC 公开循环诊断日志候选方案

这是产品专用候选方案，不是仓库默认分区，也不表示已经迁移实体卡。
保留 `partitions.csv`，在隔离构建中组合
`sdkconfig.defaults;sdkconfig.pocket-logs-candidate`。只有四个分区描述全部精确
匹配候选方案、未加密且可写时，适配器才创建任务并访问 Flash。

## 分区及数据影响

| 区域 | 现有偏移/大小 | 候选偏移/大小 |
| --- | --- | --- |
| NVS | `0x9000 / 0x6000` | 不变 |
| PHY | `0xF000 / 0x1000` | 不变 |
| factory | `0x10000 / 0x7F0000` | `0x10000 / 0x7D0000` |
| pocket_logs，data 子类型 `0x40` | 无 | `0x7E0000 / 0x20000` |

获准迁移后，写入分区表扇区 `0x8000–0x8FFF`，以及从 `0x10000` 开始的已核验
应用。应用的准确长度、扇区范围和 SHA 必须来自匹配构建证据。没有有效日志历史时，日志器
擦除 `0x7E0000–0x7E0FFF`，写入 64 字节扇区头和 64 字节 BOOT 记录；运行中会
逐步擦写整个 `0x7E0000–0x7FFFFF`。此范围原属于 factory，不能假定尾部任意数据
可丢弃；批准范围必须覆盖完整 128 KiB，不能擅自读取或擦除。已有有效日志历史（例如回滚后
再次启用）会恢复并追加，不主动清空，首次轮换可能位于专用范围的其他扇区。

这些操作不改变 NVS/PHY 位置、不读取 NVS 秘密、不主动擦除存档、归属、中继
密钥或 BLE 配对记录；应用正常的 NVS 更新仍继续。迁移禁止全片擦除及填充合并
镜像。回滚恢复匹配的原应用及最小分区表，保留 NVS；原日志字节可留在恢复后的
factory 尾部，不再访问。额外数据或安全设置变化须另行准确说明范围。单 factory 应用/分区表更新途中
断电，可能需要 USB 恢复，并非双槽原子更新；必须保留匹配的两个回滚分段。

本方案没有外部资源分区。应用剩余空间是 `0x7D0000` 减去新应用准确长度，不是
资源容量；本改动没有实现 Wi-Fi 外部资源入口。

## 公开记录及保留时长

共 32 个 4096 字节扇区，每个含 64 字节扇区头及 63 条 64 字节记录。扇区和记录
序号配合 IEEE CRC32 恢复已提交前缀，不反复更新全局头指针。半写记录导致切换
扇区，不确定的读写结果禁用当前实例，等待重新启动/打开。擦除或写入下一扇区头
途中断电时，最新已提交扇区仍保留。

字段为版本、类型、记录序号、启动序号、运行秒数、公开 ELF 前缀 8 字节、复位
原因、页面/游戏/按键/事件/云状态/结果/错误枚举、饱和错误计数、KiB 堆统计及
64 字节单位的主任务/日志任务栈最低余量。页面或云状态 255 表示未知，按键或
事件 0 表示无。云状态是本地概况，不能证明服务器保存成功。BOOT 使用上次有效
上下文，加上本次复位原因及固件前缀。温复位尽量恢复 RTC 上下文；上电或 RTC
校验失败则使用最近的持久记录。硬复位可能丢失最新的易失上下文。

格式不接受字符串、账号/设备身份、二维码地址、PIN、JWT、凭据、中继/BLE 密钥、
地址、不透明数据、存档内容、原始串口或内存转储。不在 panic、ISR 或 BSP 回调中
写 Flash；准确异常 PC 仍通过单独有界串口诊断获取。

低优先级任务申请 4096 字节栈；静态服务、RTC 和锁的编译上限为 1024 字节，交付
须报告目标 ELF 的实际数值。启动要求空闲堆至少 16 KiB、最大块至少 8 KiB。
分区、内存或读写失败仅禁用日志。主任务更新 RAM/RTC；后台写一次 BOOT，之后
最多每 60 秒写一条并合并错误。Flash/cache 暂停仍需实体游戏及音频测试。

循环后按扇区粒度保留 1954–2016 条记录：每分钟一条约 32.6–33.6 小时。启动和
错误也占用同一历史，不能永久保存。没有自动上传日志或新增 UI/USB 导出命令。
可移植遍历器只返回通过验证的公开记录；`tools/h2h/decode_pocket_log.py` 解析用户
明确提供的离线分区捕获，不输出原始扇区。取得捕获属于独立授权操作，须先确认
精确的专用分区。

## 爱心称呼与蓝牙

顶栏爱心图标和奖励/收藏文字“爱心”对应同一累计字段 `hearts`；每 5 点解锁一张
卡片，商店消费独立的 `star_balance` 星星余额，不扣爱心。“心心抱枕”是装饰，UI
统一显示“爱心抱枕”，不改变存档索引、布局、版本或标准模型协议。蓝牙图标使用
已编译的 Montserrat 14 符号字体，由真实 GAP 连接状态驱动；仅广播不显示，也不
证明鉴权或云同步成功。图标固定预留位置，重连不移动爱心和电量；长标题只显示
一行并截断。

## 验证与发布边界

运行静态完整门禁、默认分段固件门禁及隔离候选分区构建/布局/8 MB/RAM 检查。
主机测试覆盖 NOR 边界、CRC 损坏、循环/磨损、4227 个字节级断电场景、RTC 恢复、
写入频率、分区不匹配及内存/读写失败。真实 C/LVGL 渲染单独验证连接、断开、
重连和最大数值。构建、主机与设备结果分别报告。协调任务确认准确数据影响前，
不执行候选分区迁移；实体日志、断电恢复及音频验证仍待完成。
